# Prodesk IT -Software Development company 

Prodesk IT is a responsive Software Development company landing page designed to showcase web development, SEO, and digital marketing services.

+ Live Website

[Visit Live Website](https://github.com/ashu01-code/Prodesk-IT.git)

+ Screenshot

![Prodesk IT Website](screenshot.png)

+= Features

- Responsive design for desktop, tablet, and mobile
- Dark and light mode toggle
- Responsive navigation with mobile hamburger menu
- Hero, About, Services, and Contact sections
- SEO, Web Development, and Digital Marketing services
- Back-to-top button
- Smooth scrolling and simple animations

+= Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

+= Project Structure

- `index.html` - Website structure and content
- `style.css` - Website styling and responsive layout
- `script.js` - Theme toggle, mobile navigation, and interactive features
- `screenshot.png` - Screenshot of the deployed website
