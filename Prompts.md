# AI Prompts Used During Development

This file contains the AI prompts used during the development and improvement of the Prodesk IT landing page.

# Prompts

### 1. Website Development
Create a professional and responsive landing page for a digital agency called Prodesk IT using HTML, CSS and JavaScript.

### 2. Theme Toggle
Add a dark and light mode toggle using vanilla JavaScript and store the user's theme preference in localStorage.

### 3. Responsive Navigation
Make the navigation responsive with a hamburger menu for mobile devices.

### 4. Responsive Design
Improve the mobile responsiveness of the website while keeping the desktop design unchanged.

### 5. Performance and Accessibility
Review the HTML, CSS and JavaScript and suggest improvements for website performance, accessibility and responsive behavior.
